# Rapport

An AI conversation coach that helps people build real communication skills
for dating, social life and work, through practice, feedback and progress tracking.

## The problem
Many people feel anxious or stuck in conversations: first dates, small talk,
conflict, interviews. Human coaching is expensive, and most AI dating apps
only generate quick replies instead of building lasting skills.

## The solution
Rapport works like a gym for conversations:
1. **Practice** realistic scenarios with AI characters (text, later voice)
2. **Get feedback** scored on specific skills: listening, curiosity,
   confidence, empathy and clarity
3. **Track progress** with a skill profile that improves over time

## MVP features
- Onboarding quiz to set goals and a starting skill profile
- Scenario practice across Dating, Social and Work tracks
- Feedback report after every session
- Progress dashboard with skill trends
- Message helper: paste a conversation, get feedback and reply ideas

## Tech stack (planned)
- Frontend: Next.js
- Backend: FastAPI (Python)
- AI: LLM API for characters and feedback; Whisper + TTS for voice mode
- Database and auth: Supabase

## Status
🚧 In early development

## Principles
Rapport promotes respectful, honest communication. It is not a tool for
manipulation, and it encourages real-world connection over dependence on the app.
For adults (18+).
